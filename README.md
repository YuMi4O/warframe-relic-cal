# Warframe 虚空遗物计算器

精准计算核桃开启策略，基于蒙特卡洛模拟，帮你规划遗物开启方案。

## 功能

- 设定目标部件及需求个数，模拟刷取所需轮次
- 自定义6个部件的选取优先级
- 支持四种精炼等级：完整、优良、无瑕、光辉
- 支持两种开车方式：全上（4人）、2-2轮
- 输出各部件平均获取数量、普通车/防御车所需核桃数
- 展示轮次分位数（50%/80%/95%/99%），直观了解运气波动

## 使用方法

1. 下载 `index.html`
2. 双击用浏览器打开
3. 设置参数，点击计算
4. 无需联网，本地运行
